# Suzan & Freek Fansite

Een zelfstandige PHP/HTML/CSS-fansite.

## Installeren
1. Upload alle bestanden naar een PHP-hosting.
2. Zorg dat `index.php` de homepage is.
3. Open het domein in je browser.

Er is geen database nodig.

## Aanpassen
- `partials/data.php` bevat de demo-inhoud.
- `assets/style.css` bevat alle styling.
- Voeg eigen foto's toe in bijvoorbeeld `assets/images/`.
- Controleer rechten voordat je officiële foto's, logo's of andere beschermde media publiceert.

De site is onafhankelijk en niet officieel verbonden aan Suzan & Freek.
